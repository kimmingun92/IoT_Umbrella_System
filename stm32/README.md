# stm32/

관리실 표시부. STM32CubeIDE(HAL 라이브러리) 프로젝트의 `main.c`, `clcd.h`, `clcd.c`가 포함되어 있으며, 나머지 `.ioc`/링커스크립트/HAL 드라이버 등은 CubeMX로 프로젝트를 새로 만들어 이 세 파일을 덮어쓰는 식으로 사용한다.

## 주변장치 설정
| 주변장치 | 용도 | 설정 |
|---|---|---|
| USART2 | PC 디버그 콘솔 (printf 리다이렉트) | 115200bps |
| USART6 | 블루투스 모듈(HC-06 등) 연결 | 9600bps |
| I2C3 | I2C LCD(1602, 16x2) | 10kHz |

`clcd.h`/`clcd.c`는 I2C LCD 제어용 헬퍼 라이브러리(`LCD_init`, `LCD_writeStringXY` 등)로, `main.c`에서 그대로 호출한다. ARM 툴체인·STM32 HAL 없이는 컴파일 검증이 불가능한 영역이라 이 파일들은 실제 빌드까지는 확인하지 못했다.

## 동작
1. 3초마다 `[YGY_BLT]UMB@ALL\n`을 UART6(블루투스)로 전송해 라즈베리파이 블루투스 중계 클라이언트에 전체 슬롯 상태를 요청한다.
2. 응답으로 받은 `[UMB]1:EM@2:DR@3:EM` 또는 `[SLOT]1@DRYING@45@06-01 11:38` 형식 문자열을 파싱해 LCD 2줄에 표시한다.
   - 상태 코드: `EM`=비어있음, `US`=사용중, `DR`=건조중, `DN`=건조완료, `TF`=도난
